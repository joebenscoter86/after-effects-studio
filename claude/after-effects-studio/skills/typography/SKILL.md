# Typography in motion

Read ae_library documents **motion-language**, **production-workflow**, **brief-template**, then **typography-technique** and **typography-recipes**. This skill starts independently; do not assume motion-studio already ran or hand the task back to it. For a worked treatment read **typography-examples**. Load **typography-jsx** when using the native helpers.

If tools are unavailable, the same bundled files are at ../../library/language/core.md, ../../library/language/production-workflow.md, ../../library/templates/brief.md, ../../library/techniques/typography.md, ../../library/recipes/typography.md, ../../library/examples/typography.md and ../../library/scripts/typography.jsx relative to this skill directory. No original Content repository or private rig is needed.

Identify the exact copy, primary message, text roles, hierarchy, intended voice, format, palette, reading order and resolved hold. Infer aesthetic defaults from the request; ask only about missing information that changes the result. Choose installed faces for the role and record resolved PostScript names/fallbacks. House fonts, positioning and JoeB appearance are optional. Keep text editable; do not rasterize it as the default.

Inspect AE state and discover native operations through ae-control before writes. Choose a mechanism for what the words do: clean arrival for reading, stagger for ordered emphasis, mask for disclosure, restrained impact for a single emphasis, aligned replacement for a meaningful change. Current helper scope is horizontal Latin; unknown scripts need another verified native approach or an explicit limitation. Face cycling is not a supplied tested capability.

Measure after font resolution. Fit full copy above a readable minimum; fix layout when overflow persists. Preserve keyed/expressed Source Text and unrelated layers. Use exact owned IDs and inspect partial native failures before retrying. Review actual readable, action, overlap and landing frames, plus full-speed playback when available; state omissions. Check glyphs, line breaks, spacing, contrast, accent collisions, safe margins and enough settled reading time. Separate technical correctness, your visual judgment and the user's approval.
