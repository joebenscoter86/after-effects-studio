# Reusable scene recipes

Each recipe is an explanatory operation, not a premade sequence to apply everywhere.

## Construct → resolve

Use when a vague idea becomes a clear object. Reveal baseline and guides, draw the outline, introduce the material object, then cut the guides on the resolving word. Retain the same anchor throughout. Stagger detail by 2–3 frames. Inspect the hand-over for double edges. Native paths and masks own the construction; the final object may be a supplied still.

## Selection → organization

Use for files, tasks or information becoming ordered. Begin with deliberately seeded offsets; a sweep selects each object as it crosses it. Selection handles pop sequentially. Objects straighten, then travel to a legible row or container. Match two states of a container by measured shared geometry, not nominal image dimensions. Keep meaningful source labels; don't invent results.

## Fill → reveal a number

Use for progress, budget or comparison. Draw the baseline from its center, grow the bar from a left anchor, and drive the exact count from a named slider. Set a real maximum and unit. Couple color change to the meaningful threshold. A blank supplied/generated screen can carry native UI; no fabricated generated digits.

## Stamp / badge confirmation

Use to confirm a completed action after the evidence is visible. Reveal the main state first. Place the badge at a corner that does not cover the proof. Use a short scale launch into a restrained spring; preserve an image badge's base scale. A detached check or seal must be a separate layer.

## Discard / collapse

Use when something is removed, simplified or rejected. Small anticipation; squash the selected object toward an intentional pivot; collapse or drop along the established spatial axis. Clip inside a container with a matte and a front-rim layer when needed. Hold the cleaned-up after-state so removal has meaning.

## Whip transition

Use when successive scenes belong to one visual space. Group outgoing and incoming scenes under separate nulls, with anchors established before parenting. Apply the measured acceleration profile from `timing`. Start incoming assets on the fastest frame. Render before/during/after to find exposed comp edges and clipped overshoot.

## Typography-led section

Use when language carries the idea. Establish a readable held headline; animate a supporting phrase by masks, text animators or position with a small stagger. Use a second type style only when it adds meaning. Fit actual bounds; don't solve overflow by shrinking everything. Keep subtitles subordinate to the title; avoid a competing karaoke highlight unless the brief calls for it.
