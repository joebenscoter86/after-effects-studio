# Package boundaries

Claude discovers `.claude-plugin/plugin.json`, six skills in `skills/` and the server in `.mcp.json`. The server entry is `node ${CLAUDE_PLUGIN_ROOT}/start.mjs`. `start.mjs` checks for Node.js 24, turns custom scripting on unless the environment already sets `AE_MCP_ENABLE_EVAL`, and imports `runtime/dist/index.js`. The server talks to Claude over standard input and output and uses the upstream local OS-scripting and file-mailbox transport to control After Effects. It opens no network port and uses no cloud relay.

`runtime/dist/` holds the server's own code, compiled file by file from the upstream TypeScript so a reviewer can read it. `runtime/node_modules/` holds only the dependency files the server imports, copied unchanged with their licenses; nothing is fetched or installed at startup. `runtime/jsx/` holds the ExtendScript the server sends to After Effects. Node and After Effects remain prerequisites on the user's Mac.

`ae_library` reads only IDs listed in `library/manifest.json`, checks path containment and content hashes, and works with After Effects closed. `ae_catalog` lists the operations the server will actually run under the current policy; custom scripts use `eval.run` when it is enabled. The library index returns a `startHere` route to motion-language, production-workflow and brief-template. The server instructions and the motion-studio skill ask for that foundation before creative work, then load the technique modules the scene needs. This is guidance for Claude, not a runtime guarantee.

The library holds 91 indexed documents and code helpers, including the foundation, typography and paper-collage modules, native helper code, worked scenes, a failure atlas, and a visual style library: 30 styles in `library/styles/`, each a `STYLE.md` and an ES3 module plus the tools some need, indexed by `library/styles/index.json` and routed by the `visual-styles` skill. Source hashes and a migration matrix make the adaptation inspectable. The package does not include asset generation, licensed media, a panel inside After Effects, or Joe Benscoter's production system. The JoeB look is an optional preset with explicit rig dependencies; ordinary scenes use the independent helpers and native operations.

The package is generated from the repository's `plugin/` folder by `release/build-claude-package.mjs`, which also enforces the directory's file rules. Other After Effects controllers must be run one at a time by the user. Inspect the exact open project before writes; the local After Effects application is shared.
