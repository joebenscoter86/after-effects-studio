## Failures, corrections and labor

1. First build used `native` as an ExtendScript variable; parser rejected it before construction. Project inspection confirmed zero items before the corrected attempt.
2. Next build tried Bezier easing on Source Text, which only accepts held interpolation. It stopped with two owned comps and five master layers. Inspected exact IDs, removed only those owned items, gated easing on supported interpolation and rebuilt successfully.
3. A template query failed because the queue was empty. Added the owned master to the queue, discovered actual installed templates, then chose Best Settings / High Quality.
4. Frame review exposed a center-accent pivot error and overlapping separated parts. Corrected the pivot, spaced the nine components into a grid and separated the linked surface. Subsequent refinements narrowed the curved fins, smoothed the anticipation, tied labels to the intended parts, increased label breathing room and made the ending fully still. Three native visual-correction passes, separate from the two build-script repairs.
5. Reusing a completed render item returned warnings that AE cannot change its render flag/output file. A following render call returned success with a queue count despite producing no new final file. Checked file absence, added a fresh queue item, set its output successfully and rendered the actual corrected file. The tool's `rendered` count must not be treated as proof of newly rendered files. This runtime result-reporting weakness is recorded for follow-up; no runtime source patch was made in this probe.
6. QuickTime file navigation once truncated the typed path; setting the observed path field recovered it. A UI-state-change guard also required a fresh state read. No human AE authoring or UI intervention was needed.

No native timeout, uncertain write replay, font fallback, missing-media failure or unrelated-project loss occurred. Native construction and corrections used agent-authored ExtendScript through the installed plugin; this was not a one-click or zero-intervention run. Two actual full renders reported 77.683s and 70.338s. Active continuation through completed visual/playback review took about 16.6 minutes, plus report/audit/handoff preparation; the earlier stopped preflight and time awaiting clarification are separate.
