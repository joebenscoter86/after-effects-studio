## V11–V13 material-coupling study

Joe reviewed v9 and said the writing still read as an overlay. V11 tested native Bevel Alpha and paper-driven Texturize on the final invitation in separate rendered frames. The bevel visibly raised the letters, which is opposite the desired pen-pressed effect; Texturize made too little difference at presentation scale. Both were judged inadequate, and v9 remains the latest technically verified full movie.

`ms-06-pressed-ink-proof.py` is a development-only deterministic proof. It renders the exact invitation copy in an installed handwriting font and uses the photographed paper luminance to warp the stroke and modulate pigment load. V12 replaced only the final card with this proof and rendered a 10.5-second frame. The result preserved paper variation through the ink, but the font silhouette and smooth edge still looked digitally typeset. This proof requires local Python, NumPy, SciPy and a macOS font; it is not a packaged plugin feature.

V13 tested an image-edited version of that same paper with the exact invitation copy rendered as handwritten dark-green ink. The source image, full-comp 10.5-second frame and separate owned AEP are saved as ignored local review media: `ivory-handwritten-reference.png`, `v13-handwritten-reference.png` and `community-garden-v13-handwritten-reference.aep`. The frame was rendered and visually inspected. The result is materially closer to the requested ink-in-fibers appearance, though this is a **static visual reference**, not an accepted example or a verified full movie. The model preserved the two exact sentences in this one generation, but that does not establish reliable spelling for arbitrary copy. In v13 the original native Source Text remains in the project but is disabled; the visible letters are baked into the paper image and therefore require regeneration after copy edits. Its animation is not yet rebuilt. Do not claim the v13 treatment is editable live AE text or mark AFT-45 Done on this evidence.

The proposed scalable path is a linked material workflow: keep exact copy as native Source Text; generate a paper-coupled pigment/indentation pass from that copy and the actual paper texture; refresh it automatically when copy changes; retain the native source and a generator-free fallback. First close the visible gap to the v13 reference, then test exact spelling, refresh behavior, animation, portability and the complete 12-second export. If the visual target cannot be reached deterministically, image-generated lettering can remain an optional hero-render mode with its editability tradeoff explicit.
