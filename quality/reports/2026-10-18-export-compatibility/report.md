# AFT-47 — original MOV compatibility diagnosis and bounded correction

This is a read-only media diagnosis of the preserved frozen `MS-06-lower-cost-2` output. No AE project was opened or changed. The original `quality/renders/2026-10-17-motion-system-comparison/MS-06-lower-cost-2/movie.mov` remains untouched.

The 12-second, 360-frame original contains QuickTime Animation (`qtrle`) RGB24 video. ffprobe and a full ffmpeg decode succeed, but QuickTime Player presents an incompatible-file alert. A lossless video-stream remux into a fresh MOV is rejected too. A direct H.264/yuv420p MP4 copy of the preserved original reaches 12 seconds in QuickTime. Local AVFoundation inspection gives `isReadable=true, isPlayable=false` for the original and remux, but `isPlayable=true` for the H.264 copy and for a working ProRes MOV from the same frozen batch. The `Referenced QT chapter track not found` warning is also emitted by a playable ProRes original, so it is not sufficient to explain this rejection. The supported conclusion is that this host's native playback stack rejects this export's video format while software decoding accepts it; the exact AE encoder setting or format-description incompatibility is not independently isolated.

This is one bounded original-export compatibility failure, not a failed scene or damaged AEP. The frozen comparison ledger remains 16/16 full software decodes and 15/16 candidate originals reaching the end in QuickTime; the exceptional slot has a separately verified review copy.
