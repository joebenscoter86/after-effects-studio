# Comp Room 0.4.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Comp Room 0.4.1: the seven code and guidance fixes from the finish-line reel, plus the merged `subject.motion_edge` cut-out, on a green `npm run check`.

**Architecture:** Runtime changes live in `plugin/runtime/src` (TypeScript that generates ES3 ExtendScript), with vitest tests in `plugin/runtime/tests` that run the generated JSX against recording fakes in `node:vm`. Style code lives in `plugin/library/styles/*.jsx` (ES3, loaded after `styles/aes-lib.jsx`). Guidance lives in `plugin/library/**.md` and `plugin/skills/*/SKILL.md`. The Claude package `claude/comp-room/` is generated from `plugin/` and `claude/src/`; never edit it by hand.

**Tech Stack:** TypeScript 6, vitest 4, oxlint, oxfmt, esbuild (bundle), ES3 ExtendScript, Node 24.

**Spec:** `docs/superpowers/specs/2026-11-16-comp-room-0.4.1-design.md` (approved 2026-11-16). Read it before any task.

## Global Constraints

- Tests first for every code change; watch each new test fail before writing the code.
- Nothing shipped names Joe, his brands or a creator. Third-party effect match names and product names are allowed only inside the licence table and the styles that already depend on them (Deep Glow in pixel-headline). The keyer for `subject.motion_edge` stays a parameter.
- Commit by path; never `git add -A` or `git add .` (an untracked `.build/` exists). Never push, tag, open a PR or publish.
- One After Effects controller at a time: no task touches After Effects. Live checks are Task 8, arranged through the parent session.
- Generated output goes in the same commit as the source that needs it:
  - runtime source change → `cd plugin/runtime && npm run build && node ../scripts/build.mjs` (tsc writes the per-file `dist/`, then esbuild rewrites the bundled `dist/index.js`, `THIRD-PARTY-NOTICES.txt` and the library manifest);
  - any `plugin/` or `claude/src` change → `node release/build-claude-package.mjs`.
- Library markdown/JSX edits: rebuild the manifest (`node plugin/scripts/manifest.mjs`, also run by `build.mjs`).
- Plain, short English in guidance, in the project's existing style. ES3 only in `.jsx` (var, no arrow functions, no `Array.prototype.map`).
- Gates, all from `plugin/runtime` unless noted: `npm run check`; `npm run test:offline`; `node --test 'release/tests/*.test.mjs'` from the repo root.

## Review Focus

1. Licence file present but the effect missing from `app.effects` (licence left after uninstall) → still "not installed", stock glow.
2. `o.glow: "deep"` forced on an unlicensed install → honour the explicit choice but warn that the watermark will render; `licensed: true` silences it.
3. Idle report on a layer whose in/out span is shorter than the threshold, or that is trimmed so it is on screen only partly → measure only the on-screen span clipped to the comp; never flag.
4. Idle report on a precomp with keys inside it but outside the span being measured (keys before the layer's in point, after time remap / start time offset) → map inner key times through `startTime` (and stretch) before deciding.
5. `subject.check` / `use_cutout` / `render_cutout` on a comp that has BOTH a soft-edge layer and a motion-edge layer (one applied after undoing the other is fine; both at once) → refuse with a clear message rather than pick one silently.

Each line has a test in its owning task (marked "RF-n").

### Task 5: Idle-layer report in `ae_check_comp` (spec item 4)

**Files:**
- Modify: `plugin/runtime/src/tools/check-comp.ts` (schema, report assembly, text sheet), `plugin/runtime/src/tools/check-comp-jsx.ts` (collect per-layer change times in AE)
- Test: `plugin/runtime/tests/check-comp.test.ts` (or a new `check-comp-idle.test.ts` using the same fake)

**Interfaces:**
- Tool argument: `idleSeconds?: number` (default `5`, `0` disables).
- Report field: `idle: Array<{ layer: string, index: number, from: number, to: number, seconds: number }>`, sorted by `seconds` descending; listed under a "Report (not faults)" heading in the text output; never adds to faults or changes pass/fail.
- JSX side returns, per layer, the sorted change times inside the layer's on-screen span `[max(inPoint,0), min(outPoint, comp.duration)]`, or `"always"` when it changes continuously. TS side finds the longest gap (including span start → first change and last change → span end) and reports it when `> idleSeconds`.

Change sources (spec): keyframes on the layer, its effects and masks (walk the property tree); keyframes on every parent up the chain; a layer marker; a text animator whose properties are keyed; for a precomp layer, keyframes one level down mapped to outer time (`outer = layer.startTime + inner * stretch/100`) (RF-4).
Time-driven expression (builder's call, record it in a code comment): an enabled expression whose text matches `/\btime\b|wiggle\(|loopIn|loopOut|valueAtTime|posterizeTime|Date\(/` counts as `"always"`; Source Text included.
Exempt: footage/audio layers whose source has duration (video/audio that plays); cameras, lights, nulls, adjustment and guide layers; solids and stills that cover the whole frame and sit at the bottom of the stack (no non-exempt layer below them).

- [ ] Failing tests, each with exact expectations:
  - a shape layer on screen 0–12 s with no keys → `idle[0]` `{from: 0, to: 12, seconds: 12}` (the finish-line command bar).
  - same with `idleSeconds: 15` → `idle` empty; `idleSeconds: 3` and keys at 0 and 4 s on a 0–12 s layer → one entry 4–12.
  - keyed parent → not flagged; marker at 6 s → longest gap 6 s, with threshold 5 still flagged as 6–12; `wiggle()` expression → not flagged; a plain `value + [0,10]` expression → flagged.
  - precomp with inner keys every 2 s → not flagged; RF-4: precomp with `startTime = 10` whose inner keys are at 0–2 s inner time → keys map to 10–12 s outer, so 0–10 s idle is flagged.
  - exempt: camera, null, adjustment, a playing footage layer, a full-frame bottom solid → never in `idle`.
  - RF-3: a layer on screen 0–3 s with no keys, threshold 5 → not flagged; a layer with `inPoint = -4, outPoint = 8` → span 0–8.
  - idle entries never change the report's fault count or verdict.
- [ ] Run; expect FAIL. Implement. Pass.
- [ ] Mention `idleSeconds` and the idle report in `ae_check_comp`'s tool description and in the motion-review guidance where `ae_check_comp` is described (one line).
