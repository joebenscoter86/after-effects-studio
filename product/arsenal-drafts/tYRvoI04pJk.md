## Glossy red pill button that swings up from below in 3D
id: 01-gradient-pill-button-3d-entrance
status: proven (accepted by Joe 2026-11-26: rebuilt in After Effects on generated artwork from this recipe alone, reviewed against the tutorial's result and phone MP4s sent; he said "approved")
source: tYRvoI04pJk 91–349 s
jobs: depth and finish; camera and 3D; energy and impact
what it does for a beat: A hook moment where a call-to-action button should arrive as a big event rather than just fade or pop. The button comes up from below, near the camera and tipped back, and settles flat in the middle.
what it looks like: A wide red rounded-rectangle button (corner radius about a quarter of its height, not a capsule) with a soft left-to-right gradient and a slightly lighter thin edge, white "Upload" label and a white upload icon on a black ground. It rises from the bottom edge, large and tilted, and eases down into a flat, centred button.
ingredients:
- Rounded Rectangle tool with a Linear Gradient fill and a Solid Color stroke — built-in; shape layer (shown f003259)
- Text tool — built-in; white text (said)
- Tint effect on the icon PNG — stock; Effects & Presets, searched "tint" (shown f005730)
- Classic 3D layer switch, parenting (pick-whip / Parent column) — built-in (shown f007581)
- X Rotation and Position keyframes with Easy Ease (F9) — built-in (said)
- Graph editor, speed graph — built-in (shown f008518)
steps:
1. Draw a rounded rectangle on a new shape layer with the Rounded Rectangle tool (said; it was already a 3840×2160, 25 fps comp, shown f002527)
   - The tool bar's "14 px" is the stroke-width field (reads 1,4 px, shown f002249); the tool bar has no corner-radius field, so no radius is set here.
2. Set Fill to Linear Gradient and open the gradient editor (said; editor shown f002527). Make two stops, both red: the first a brighter red, the second a bit darker (said; "same hue" is not said). Typed values not visible. (said)
   - Rendered colours sampled on the finished fill: left end about RGB 221–224,11–12,12, right end about 189–192,13–15,13 (measured, source 332.6 s; rendered, not the stop values). Warning: a saturated red measured on a screen recording can be inflated by a wide-gamut display, so aim for "bright red to slightly darker red", not these exact numbers.
3. Set Stroke to a lighter red than the fill (said). Stroke colour swatch is red (shown f003259).
   - Stroke Width: 1.4 px at first (shown f003259), then raised to 4 px (said "maybe four"; 4 shown f007581)
4. Drag out a wide rounded rectangle, then raise Roundness a lot (said).
   - Roundness: 147 (shown f003476 and f007581; f003259 has the field mid-edit and unreadable)
   - Size: 1734.5 × 566.2 while drawn (shown f003259). It is narrowed later, after the label and icon exist (see step 9).
5. Switch to the Selection tool (V) and drag the gradient handles so the gradient is soft: start point just inside the left edge and a little above centre, end point past the right edge and a little below centre, a faint downward slope (said; the end handle's place is shown f003476, but the start handle is mid-drag there with the mouse on it, so its exact spot is inferred)
6. The faint glowing edge comes from the 4 px stroke of step 3 (said); check the button plays well first (said).
7. Add a text layer "Upload", fully white, sized moderate (said; no size given). Place it right of the icon (shown f005730).
8. Import the upload icon PNG, add Tint (Map Black To white via Swap Colors, Amount to Tint 100 %) so it is white (said "swap colors"; values shown f005730)
   - Scale: 42 % (shown f005730)
9. After the text and icon exist, unlink the shape's Size proportions and narrow it from 1734.5 to 1406.5 wide, height 566.2 (said "unlink"; values shown f007581). Then centre the shape with the Align tool (said/inferred, no menu on screen) so Position reads 1920, 1080 (shown f008518), and move the label and icon by eye to sit centred as a pair (said "eyeballing"). Order matters only for the by-eye placement.
10. Turn on the 3D switch for the shape, text and icon layers (said "make it all 3D"), keep the classic 3D renderer (said, shown f007581 "Classic 3D"). Parent the text and icon to the shape layer (said, shown f007581 Parent column).
11. Press P and R on the shape; only X Rotation is used (said). Set a keyframe on Position and X Rotation at time 0 and a second pair about a second later (said "one to one and a half seconds"; second key sits at about 1 s 03 f, inferred from the playhead on it in f008518).
12. At the second key (the end): Position 1920, 1080, 0 and X Rotation 0° (shown f008518).
13. At time 0 (the start): drag the layer toward the camera by the third Position value, holding Shift (said), and down; then rotate on X (said).
   - Position: 1920, 1489, −3580 (shown f007581)
   - X Rotation: −77° (shown f007581; −78 passed while dragging, −77 settled). The author wants it not completely flat (said)
14. The ease that makes the result is the third-party plugin ease-out the author names (said, 5:19.9; the plugin's name is not clear and no panel is on screen): a strong ease-out, fast at the start and slow at the end, with little ease-in (inferred from the played result: button width about 2.0×, 1.36×, 1.0× of final at three successive redraws). Do this with the plugin or, by hand, as in step 15. The author's other option, Easy Ease on all four keys (right-click → Keyframe Assistant → Easy Ease, or F9; said, menu not on screen so path inferred), is shown only as an option and never played; a symmetric F9 ease does not give the result's fast-start, slow-end shape. The speed graph in f008518 is a dragged-handle state (tooltip "X Rotation 32,20 °/sec" and the pointer on the last key's handle), not a finished ease.
15. By hand, same result: in the graph editor, speed graph (not value graph), drag the last key's handle to the left (said; graph shown f008518, mid-drag) so the speed is tall and narrow just after the first key and tails off long before the end.
layout: Picture is 3840×2160. Finished flat button: 1406.5 × 566.2 px = 36.6 % × 26.2 % of the picture, centred (measured, source 332.6 s: box 264 of 719 px wide, 106 of 405 high; matches the typed Size). Label and icon sit centred as a pair, icon at the left; icon is 42 % scale; label "Upload" (ascender to descender) about 30 % of the button height, capital U about 25 %, icon about 34 %, gap between icon and label about 47 px of a 1438 px-wide crop, i.e. 3.3 % of the picture width (all measured on source 332.6 s, button 214 px high in that crop). Corners are a rounded rectangle, not a capsule: Roundness 147 is a 147 px radius on a 566 px high shape, about 26 % of the height (half the height, 283 px, would be a capsule); on the result tile the radius measures about 60 of 213 px high, about 28 % (measured). Ground is plain black; no shadow, no glow. Gradient runs along the long axis, brighter red left, darker right, faint downward slope; stroke is a lighter red 4 px, reads as a thin bright rim. Motion (result frames 331.7, 332.0, 332.3 s of source, centre of the picture crop): the button first shows only its top rim at the bottom edge, then is about a third (37 %, measured) wider than its final width, about twice final width at 331.84 s with its lower edge wider than its upper edge (so the bottom edge is nearer the camera, measured from the trapezoid), centre about 62 % down the picture, then rises and shrinks to centred. Speed graph shape: peak soon after the first key, then a long slow tail into the last key (ease-out); not symmetric. All three layers move together via parenting. Other traits from the screen: the picture beyond the button is empty black the whole time; the later bounce on icon and text belongs to recipe 02 and is not part of this entrance (the entrance shows icon and label already present).
timing and easing: Two key times, 0 and about 1 s 03 f (28 frames, inferred) on Position and X Rotation only. The result's ease is a strong ease-out (plugin, said 5:19.9; or the hand-dragged last handle, step 15); F9 Easy Ease is the author's other, unplayed option. The graph in f008518 is mid-drag, so exact influence is not readable. In the recording the viewer redraws about 14 times between 331.72 and 332.36 s (settled by 332.40 s) against a 28-comp-frame move, so the preview skipped about half the frames; the result shows the move's path and settle, not every frame. Do not take timing from video seconds.
variations: Could be a pop instead; the author prefers the fly-in because this is the hook (said). Colours can be changed later (said); tint lets the icon colour change later (said).
pitfalls: Use the speed graph, not the value graph, to see the ease (said). Do not make it completely flat at the start (said). Rotation on X only (said).
longest on: Shape styling is the longest block (1:28–2:37, about 69 s: fill, stroke, roundness), then text, icon and tint (2:37–3:27, about 50 s), then the ease (5:11–5:45, about 34 s), then resize and centre (about 25 s) and the start pose (4:43–5:07, about 24 s). Timed from the timeline's sentence times.
build notes: Shape layer → Add Rectangle, Rounded Rectangle path Size 1406.5×566.2 and Roundness 147; Fill → Gradient Fill type Linear with start/end points set; Stroke width 4. Layer Transform Position and X Rotation need 3D enabled (threeD = true) on shape, text and icon layers; parent the text and icon to the shape. Keyframe Position [1920,1489,-3580] → [1920,1080,0] and X Rotation -77 → 0 over about 28 frames; set ease with KeyframeEase: high influence (inferred, about 80–90 %) on the last key's in and low on the first key's out and the last key's out; values inferred. Tint effect: Map Black To white. Gradient handle placement (start handle exact spot unknown) and selecting the graph editor mode are by hand. Default comp camera (no camera layer) is used.
