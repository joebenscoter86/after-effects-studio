# Arsenal menu: 64 checked recipes from five videos

## How to use this

Pick the section for what the beat needs, scan the one-line entries, then open the recipe in `<video id>.md` under its number.
A recipe is listed under every job it serves, so the same entry can turn up in several sections. Each section starts with the entries most likely to be useful.
`unproven` means the recipe has not yet been built in After Effects and compared with the tutorial's own result. Treat every value as a starting point until it has been.
The last three sections are planning notes for whoever improves the library: duplicates to merge, shared parts, and where the recipes are weakest.

The `layout` gap is closed: every recipe now has a measured layout line, where 25 had none before. The weakest point is now the result itself. More than half the recipes have no clean, lasting frame to compare a build against, and eleven point at a different build or none, so a pixel comparison will often need masks or a check by value instead. Next come the settings and the motion the video never shows, and the starting sizes, which the measured layouts give only as shares of the finished picture. Curves points and puppet pins still come up most among the hand-only steps, so a library of saved presets would close much of that gap. The new carousel recipes add one more: pasting a mask path into Position has no script route, so those builds need the path drawn as keyframes with tangents.
