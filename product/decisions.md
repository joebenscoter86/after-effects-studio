# Product decisions

- D-001 — Build a universal motion plugin: user-defined subject and style, with the production-derived motion language as the default craft foundation.
- D-002 — Pursue a full public v1 release. Demonstrate capability through complete examples, editable output and meaningful revisions.
- D-003 — Launch free; decide monetization later. Do not add billing or paid tiers for v1. Free use does not decide redistribution licensing.
- D-004 — Develop in this independent After Effects Studio repository. Four workspaces: product, plugin, quality and release. This structure was approved by Joe in the originating task.
- D-005 — Maintain AGENTS.md as the canonical map; CLAUDE.md is a pointer. The plugin's bundled library is its single maintained craft source.
- D-006 — Launch publicly through a Git-backed Codex plugin marketplace with a guided install. Pursue the universal-directory route for local AE access in parallel; directory confirmation is not a prerequisite for the Codex launch. Git is the package source, not a required creator skill. This choice does not authorize repository publication, outreach or submission.
- D-007 — Scope the initial v1 host to local Codex desktop on macOS with After Effects 2026. Advertise only the exact OS, AE, Codex and Node builds that pass candidate acceptance; validate Node 24 before retaining it as the minimum. Windows, older AE releases and other hosts require separate evidence before support claims. One genuinely separate Mac is the portability gate and Joe may operate it; that run is not novice-usability evidence.
- D-008 — License Joe's original plugin additions and motion library for free personal, organizational, client and commercial motion creation. Permit ordinary installation, updates, private adaptation and delivery of rendered or editable motion outputs without output credit. Reserve redistribution, repackaging and resale of Joe's original plugin/library as a standalone product. Preserve the upstream MIT runtime and dependency rights separately. The exact grant is in `../license.md` and the installable `../plugin/license.md`; final legal and asset review remains a release gate. On 2026-11-09 Joe approved License 1.1 ("no issue"): it names the Claude package, Comp Room, and lists the authorized sources (the public repository and its marketplaces, the Comp Room directory listing, and organization admins passing on unmodified copies to their own members). It is applied to `license.md` and `plugin/license.md` and reaches Codex in its next version.
- D-009 — Use JB Technology LLC as the public plugin publisher and developer identity, per Joe's direction. This identifies who publishes and supports the release; it does not itself transfer copyright in Joe's original materials. The final product name is After Effects Studio. Use Joe's existing `joebenscoter86` GitHub account for the public repository and its Issues as the initial support intake. A custom domain and dedicated support email are not launch prerequisites. Public website, privacy, terms and support URLs still require an actual owned repository/page before they enter release metadata. This choice does not authorize making the repository public.

- D-016 — On 2026-11-09 Joe renamed the Claude plugin **Comp Room** (slug `comp-room`, display name "Comp Room"), amending D-009's product name for the Claude package only. Two findings drove it. Anthropic's directory screens `name`, `displayName` and `author.name` for confusion with well-known brands, so a new slug under the old display name would not avoid a hold. Adobe's trademark guidelines for plug-in developers forbid an Adobe mark in a product name and allow referential use such as "for Adobe After Effects". No Claude listing or install existed, so the rename cost no user an install. A clash check (not exhaustive, not legal advice) ruled out Gatemark (a company of that name sells AI-agent tooling) and Keyframe Studio (Keyframes Studio is a live motion-design web app; Keyframe Studios is a London animation studio); Comp Room turned up no clash. Shared `plugin/` text that reaches the Claude package now says "this plugin" instead of a product name and reaches Codex in its next version. The Codex package, its marketplace entry and the repository keep the After Effects Studio name; renaming them is Joe's separate call. USPTO and EUIPO exact-match searches remain before publication. This decision authorizes no publication.

No public publication or outreach is implied by these decisions.
