# Portable motion brief

Use before building a new piece. Scale length to the task and keep it in the user's project for context-independent resumption.

## Project

- Viewer takeaway:
- Duration / aspect / resolution / fps:
- Style, material, palette roles and available fonts:
- Exact target AE project/comp; preservation of unrelated work:
- Inputs: files, narration/transcript, reference, factual data:
- Delivery: editable project/assets, review clip, master spec:
- Missing dependencies and resolution:

## Scene N — start/end

- Operation (active verb, before → action → after):
- Star / stable anchor / identity across the scene:
- Title and other reading jobs:
- Start/action/payoff poses and hardest overlap bounds:
- Inspected assets; native/supplied/generated/illustrative/evidence status:
- Material, depth, shadow, occlusion:
- Events: frame/time, change, subject, target, spoken cue, duration/ease:
- Semantic turn/snap; accent response:
- Camera subject, destination, duration, hold and purpose; or intentionally static:
- Incoming/outgoing hand-off, visibility boundaries, carried objects:
- Exact on-screen numbers/text and sources; illustrative labels:
- Material assumptions or choices:

## Build/review

- Representative section: hardest hand-off plus ordinary explanation/proof.
- Ownership prefixes and reusable controls.
- Check times: first-readable, action peak, overlap, hold, seam neighborhood.
- Risks: text fit, coverage, alpha, duplicates, continuity.
- Playback/VO/audio checks and anything unavailable here.
- Expected project state, stale-build detection and delivery checks.

Event count diagnoses a chosen fast construction style; it is not a mandatory quota for a slow title or quiet proof. Every scene needs a meaningful change or an intentional hold. If feedback changes the operation, revise this brief before layering local fixes.
