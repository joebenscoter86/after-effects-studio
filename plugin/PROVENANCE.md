# Source provenance

Native runtime: [kumo.productions/mcp-aftereffects](https://github.com/kumoproductions/mcp-aftereffects), commit `d0b910c00656559583aeede310b7fb80c25d2cce`, version 0.3.1. MIT license and copyright notice are preserved at `runtime/LICENSE`. This plugin adds its own server identity/instructions, an offline hashed motion-library tool, bundled packaging and library tests. Dependency lockfile updates address available security fixes. It does not claim authorship of the upstream runtime.

Motion guidance and helper code: Joe Benscoter's Content pipeline, inspected 2026-10-06. Source files: `production/joeb-motion-playbook.md`, `production/after-effects/house/house.jsx`, `production/after-effects/house/motion.jsx`, `production/joeb-star-workflow.md`, and the house-polish prototype's `mining/FINDINGS.md`. The detailed production language is adapted as default guidance for all brands; appearance-specific decisions stay in the optional preset. Additional sources include the VO-motion workflow, reel production learnings, worked prototype scripts and CONNECT continuity retrospective. `library/source-map.json` records inspected source hashes; `docs/MIGRATION.md` maps the actual coverage and exclusions. Timings are craft starting points, not performance guarantees. The house helper asset configuration is parameterized; older helper options do not override the new no-grain preset.

The expanded motion foundation, editable typography guidance and paper-collage style were adapted from Joe's own later playbooks and examples inspected on 2026-10-15 through 2026-10-17. `library/source-map.json` records the source inventory and rights clearance for these modules. `library/modules.json` and the bundled skills route to self-contained copies here; installed users do not need the original Content repository, a private rig, a paid asset generator or its credentials. Native paper examples use procedural shapes unless separately cleared artwork is supplied. The creative evaluation keeps its original failures and later revisions as dated evidence rather than treating a selected example as universal performance proof.

The visual style library in `library/styles/` and the `visual-styles` skill hold 30 styles imported on 2026-11-08 from Joe's Content style library (commit `628f1c52`) by `scripts/import-styles.mjs`. Those packages adapt the grammar of styles from [Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar) (MIT, Copyright (c) 2026 LemoLab) into native After Effects recipes and ES3 modules written for Content; each `STYLE.md` says what it takes from its source, and the MIT notice is in `library/styles/LICENSE-lemo-opuscar.txt` and `THIRD-PARTY-NOTICES.txt`. Only styles that need no generated art are included. Font binaries, proof renders, generated pieces and Content's test-scene media are not copied (the styles name free Google Fonts families instead); the one font file shipped is `whiteboard/assets/fonts/EMSTech.json`, single-line stroke data for EMS Tech under the SIL Open Font License, with its license beside it and in `THIRD-PARTY-NOTICES.txt`; the importer rewrites Content-only notes, and `library/source-map.json` records every imported file's source path and hash under `content-style-library`.

No Higgsfield private creative skill text, proprietary FOUR Editors assets, creator footage, font binaries or Adobe binaries are redistributed; the EMS Tech stroke data above is the only font data shipped. The installed FNF fork identified the MIT upstream runtime, which was fetched independently from its public repository. Higgsfield/FNF's separately restricted skill corpus was not copied.

Some builds of this plugin bundle two contact sheets of this project's own AE test scenes in the assets folder; the Claude package leaves them out. Visual inspection on 2026-10-06 found only typography and geometric shapes, with no imported artwork, footage, visible third-party logo or private message content.
