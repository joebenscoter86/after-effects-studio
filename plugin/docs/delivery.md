# Deliver an editable After Effects project and movie

Treat the AEP, linked media and movie as one handoff. A preview frame or an unsaved composition is not delivery. Ask where the user wants the files and whether that destination may be replaced. If a destination already exists and replacement was not authorized, choose a new versioned folder; do not overwrite it. Inspect the exact AE project and confirm the scene belongs to this task before saving, switching projects or changing links.

1. **Prepare the folder.** Use an empty folder for this delivery. Put the AEP and movie in it. If the comp uses imported files, copy each permitted source into an `assets/` subfolder, preserving meaningful names and extensions. Keep an inventory of source item ID, original path, copied path and hash. Do not package media whose redistribution rights are unknown.
2. **Relink and save.** Use `footage.replace` on the existing footage item IDs to point at the copied assets, then read back every source path and run `footage.list_missing`. Save As to the intended AEP path with `ae_save_project`. A copy of an AEP alone does not collect linked files. AE may store absolute paths; the recipient may need to relink after moving the folder to another computer. Do not promise portable links until that moved-folder case is tested.
3. **Export the complete movie.** Use the AE render queue for the owned comp. Inspect `render.status` before adding an item; never clear another user's queue. Discover templates with `render.list_templates` after adding the owned item, inspect `render.get_settings`, set the intended format/path, render, and confirm DONE. `render.start` checks queued-item status and whether each target file is newly written and nonempty, but its response is not a media-integrity check: independently inspect movie metadata and decode the complete delivered file. Remove only the queue item created for this handoff if cleanup is appropriate. A frame/contact sheet does not replace a complete movie.
4. **Reopen and verify.** When the current project is saved and clean, intentionally reopen the delivered AEP. Read back the project path, comp/layer identities, native text/shapes/effects and footage source paths; check `footage.list_missing` and render a frame. Compare the output with an inspected pre-save frame. For a moved-folder or second-machine claim, test from that new location while the original source is unavailable. If AE asks to relink, disclose the step and verify again.
5. **Inspect playback and files.** Play the actual delivered movie at normal speed, including entrance, hardest overlap and final hold. Run `node scripts/verify-export.mjs <movie>` when `ffmpeg` and `ffprobe` are available; confirm duration, dimensions, frame rate and full decode. Hash the delivered AEP, movie and assets, and compare any handoff copies. State whether audio exists and whether sync was reviewed. Keep runtime correctness, visual judgment and the user's creative approval separate.

If AE cannot save, an output template is unavailable, linked files are missing, the movie fails complete decode, or a copied project only works because it can still see the original assets, report the exact failed step and keep the delivery open. Never close or replace unrelated unsaved work to run this check.
