# Privacy information for After Effects Studio and Comp Room

Publisher: JB Technology LLC. This page describes the local stdio/IPC design in the public v0.4.3 release, for Codex and for Comp Room in Claude. The native controller has grown since the tested v0.1.0 release: v0.3.0 adds whole-comp checks, subject cut-out, keying, reference measuring, delivery checks and, on macOS, a launch lock, all covered below. v0.4.0 adds `ae_arsenal`, which reads technique recipes and still images bundled with the plugin; it writes nothing and sends nothing beyond its reply to your agent. In v0.4.1, before the pixel-headline style uses an effect that renders a trial watermark until licensed, it checks only whether that effect's licence file exists in your Application Support folder; it does not read the file or send anything. They were built and checked on the development Mac in November 2026.

The bundled plugin runs a Node MCP server on your computer and uses local operating-system scripting plus temporary file messages to control your local After Effects installation. The bundled server does not start a web listener or include a hosted relay or product telemetry client. Its tools can read AE project structure, local paths and rendered frames, and can change or save a project when write access is enabled. You choose export destinations. Custom AE scripting is enabled by default and can access the capabilities allowed by AE and your machine; `AE_MCP_ENABLE_EVAL=0` disables that tool, and `AE_MCP_READONLY=1` restricts project changes.

Your instructions and the plugin's tool results pass through the agent host you use. That host's account, processing and retention practices are governed by its own terms and privacy policy. If you choose external image, video or asset services, their data practices also apply. Neither package automatically sends your project, media or renders to JB Technology LLC. JB Technology LLC receives information you voluntarily post in a support issue or otherwise send through a future support channel.

The plugin stores temporary request/response files in a per-user local mailbox. Normal operations remove their files after completion; after a crash, stale message files older than one hour are eligible for best-effort cleanup when the server starts again. On macOS the server also keeps a launch lock, so that only one script is sent to After Effects at a time: one small file per After Effects under `~/Library/Caches/comp-room/` (or the folder `AE_MCP_LAUNCH_LOCK_DIR` names). It holds a random token, two process ids, a request id and a time, nothing from your project, and is removed when each script ends; one left by a crashed server is replaced by the next call. When `ffmpeg` and `ffprobe` are installed, some operations run them locally on files you name, to read a movie or check a delivered file's sound; they send nothing anywhere. Projects, exports and other files you deliberately save remain in your chosen locations until you manage them. JB Technology LLC does not set or control the agent host's retention period or GitHub's handling of public support posts.

Ordinary support uses public [GitHub Issues](https://github.com/joebenscoter86/after-effects-studio/issues). Anyone able to view the public repository may see issue content you submit. Use redacted diagnostics and do not post confidential projects or client material. Support reports may be used to investigate bugs and improve the plugin. Security and privacy incidents use [GitHub private vulnerability reporting](https://github.com/joebenscoter86/after-effects-studio/security/advisories/new). Joe Benscoter, acting for JB Technology LLC, will triage reports and limit private-report access to maintainers who need it. Locally downloaded diagnostic copies are removed when the case closes; a reporter can request correction or deletion of supplied material through the private route. GitHub controls its own retention and backups, which this publisher cannot guarantee to erase.

You can keep the plugin in read-only mode, disable custom scripting, choose where local outputs are saved, remove local output files, and decide what to share in support. Uninstalling the plugin does not erase AE projects or exports you created. The [support page](support.md) provides the current reporting and correction route.

## Comp Room

Comp Room, the Claude package of this plugin, runs the same kind of bundled local server, and everything above applies to it. In Claude, your instructions, tool inputs and results, project metadata and requested previews pass through Claude, under Anthropic's terms and privacy policy. From v0.3.0 both packages run the same server, and two of its features touch your Mac beyond the above. When a modal dialog blocks After Effects scripting, it reads the dialog's text to report it, which needs macOS Accessibility permission for the app running Claude or Codex. Most visual styles include small Node scripts that run ffmpeg, or Blender for the 3D styles, on files you name, writing to a folder you choose; they run only when a build needs them. Comp Room's [README](../../claude/comp-room/README.md) lists everything it runs and sends.
