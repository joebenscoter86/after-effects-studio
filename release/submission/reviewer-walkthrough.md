## Product and setup

After Effects Studio is a free-at-launch local plugin from JB Technology LLC. It combines a bundled motion-design library with a local native controller that creates and revises editable After Effects compositions. The intended initial platform is Codex desktop on macOS with licensed AE 2026 and Node.js 24+. The separate-Mac run tested macOS 26.6.2, Codex desktop 26.930.61225, CLI 0.144.1, Node 26.5.0 and AE 26.5x89. Those builds are observations, not a guarantee for every macOS/AE release. The plugin does not ship AE, third-party artwork, paid fonts or a remote rendering service.

The MCP process starts locally with stdio. It uses local operating-system scripting and a temporary file mailbox to communicate with the running AE application. The tools can inspect project structure, write native layers/keyframes, render frames, save projects and export media. Before a write, the agent must inspect the exact current AE project and preserve unrelated work. The `AE_MCP_READONLY=1` setting restricts writes; `AE_MCP_ENABLE_EVAL=0` disables custom scripting. The [privacy page](../website/privacy.md) separates plugin behavior from Codex, GitHub and optional asset-service handling.

## Executable first-session prompts and observable result

Use these in a **new task with the installed plugin** and a blank/test-owned AE project. Replace the output folder with one the reviewer controls. Capture tool names and resulting comp/layer IDs; do not infer success solely from a tool's `ok` field.

| Step | Prompt or action | Evidence to record |
|---|---|---|
| Connection | “Use After Effects Studio to read the AE version and current project. Do not change anything yet.” | The plugin's own `ae_version_info`/`ae_context` tools respond; project path, item count and dirty state are unchanged. A permission failure is described without claiming a write occurred. |
| Creation | “Using only bundled guidance and native shapes/text, make a silent 6–8 second scene: three teal dots approach a closed amber gate; it opens and those same dots settle inside a destination ring. Show start, contact, opening and final-hold previews.” | One named owned comp with editable shape/text layers, stable dot identities, and actual rendered frames across the transition. Inspect edges/readability as well as file existence. |
| Revision | “In that comp, make the gate blue and open it 0.25 seconds later. Keep the same dots and unrelated project items. Show before/after frames.” | Same comp ID, same three dot layer IDs, changed gate color/timing, no duplicate scene fragments, baseline unrelated items intact. |
| Delivery | “Save an editable AEP and a complete review movie in this test folder; tell me the exact paths and any export limitation.” | Reopen AEP, inspect layers/links, play movie at full speed, check metadata and full decode, hash delivered copies. A frame preview alone is insufficient. |
| Safe failure | With a test-owned missing media/font case or an observed permission error, ask for diagnosis without replaying any uncertain write. Do not deliberately hang AE. | Error class, state inspection and bounded next action are recorded. A possible-write timeout is investigated in actual AE state before a repeat. AFT-9's controlled timeout is a separate test. |

## Claims and boundaries

The plugin makes editable motion using local AE; it does not produce a true 3D orbit from a single flat product image. Product-specific facts, prices and artwork must come from legitimate inputs. Generated external images are subject to their provider's terms and may not be unique. The three films above are proof-of-concept examples. The separate [AFT-27 capability film and late revision](../../quality/reports/2026-10-10-capability-probe/revision-report-v2.md) are complete and Joe-accepted for a first-party abstract 2D marketing brief. They do not establish the plugin's ceiling for every real-world project.

AFT-9, AFT-18, AFT-20, AFT-31, AFT-32 and AFT-34 are Done for their scoped results.
