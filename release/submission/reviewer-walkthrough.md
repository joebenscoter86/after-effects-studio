## Product and setup

After Effects Studio is a free-at-launch local plugin from JB Technology LLC. It combines a bundled motion-design library with a local native controller that creates and revises editable After Effects compositions. The intended initial platform is Codex desktop on macOS with licensed AE 2026 and Node.js 24+. Development-Mac native evidence is on AE 26.5x89; exact advertised builds require the separate-machine AFT-18 check. The plugin does not ship AE, third-party artwork, paid fonts or a remote rendering service.

The MCP process starts locally with stdio. It uses local operating-system scripting and a temporary file mailbox to communicate with the running AE application. The tools can inspect project structure, write native layers/keyframes, render frames, save projects and export media. Before a write, the agent must inspect the exact current AE project and preserve unrelated work. The `AE_MCP_READONLY=1` setting restricts writes; `AE_MCP_ENABLE_EVAL=0` disables custom scripting. The [draft privacy page](../website/privacy.md) separates plugin behavior from Codex, GitHub and optional asset-service handling.

## Claims and boundaries

The plugin makes editable motion using local AE; it does not produce a true 3D orbit from a single flat product image. Product-specific facts, prices and artwork must come from legitimate inputs. Generated external images are subject to their provider's terms and may not be unique. The three films above are proof-of-concept examples. The separate [AFT-27 capability film and late revision](../../quality/reports/2026-10-10-capability-probe/revision-report-v2.md) are complete and Joe-accepted for a first-party abstract 2D marketing brief. They do not establish the plugin's ceiling for every real-world project.
